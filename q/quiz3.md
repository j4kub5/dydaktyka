# Logika: podział logiczny, zdanie, funktory prawdziwościowe

### Zdanie w sensie logicznym to:
- [ ] Każde zdanie oznajmujące w sensie gramatycznym
- [ ] Tylko zdanie pytające lub rozkazujące
- [x] Wyrażenie jednoznacznie stwierdzające, że tak a tak jest albo że tak a tak nie jest
- [ ] Każda wypowiedź składająca się z podmiotu i orzeczenia
> Wyjaśnienie: Zdanie w sensie logicznym jednoznacznie stwierdza określony stan rzeczy i ma wartość prawdy albo fałszu. Sama forma gramatyczna lub obecność podmiotu i orzeczenia nie wystarczają; pytania i rozkazy nie są takimi stwierdzeniami.

### Które z poniższych NIE jest zdaniem w sensie logicznym?
- [ ] W grudniu 1993 r. zapytałem Piotra, czy lubi logikę
- [x] Czy Piotr lubi logikę?
- [ ] 2 + 2 = 4
- [ ] Istnieją czworoboczne trójkąty.
> Wyjaśnienie: „Czy Piotr lubi logikę?” jest pytaniem, a nie stwierdzeniem. Pozostałe wypowiedzi coś stwierdzają i mogą być prawdziwe albo fałszywe; fałszywość twierdzenia o czworobocznych trójkątach nie odbiera mu charakteru zdania.

### "Warszawa jest stolicą Polski" to zdanie:
- [ ] ekspresjonistyczne
- [ ] analityczne
- [ ] naturalne
- [x] syntetyczne
> Wyjaśnienie: Prawdziwość tego zdania zależy od faktów dotyczących Warszawy i Polski, dlatego jest ono syntetyczne. Nie wynika wyłącznie ze znaczeń słów; „ekspresjonistyczne” i „naturalne” nie są właściwymi kategoriami w tym rozróżnieniu.

### Zasada sprzeczności głosi, że:
- [ ] Każde zdanie jest albo prawdziwe, albo fałszywe
- [ ] Negacja negacji zdania ma tę samą wartość logiczną co zdanie pierwotne
- [ ] Z dwóch zdań sprzecznych jedno jest prawdziwe, a drugie fałszywe
- [x] Dwa zdania względem siebie sprzeczne nie mogą być oba prawdziwe
> Wyjaśnienie: Zasada niesprzeczności wyklucza jednoczesną prawdziwość zdania i jego negacji. Pierwsza opcja dotyczy dwuwartościowości, druga podwójnej negacji, a trzecia łączy wykluczenie wspólnej prawdziwości i wspólnej fałszywości.

### Koniunkcja (p·q) jest prawdziwa wtedy i tylko wtedy, gdy:
- [ ] Przynajmniej jedno ze zdań składowych jest prawdziwe
- [x] Oba zdania składowe są prawdziwe
- [ ] Jedno zdanie składowe jest prawdziwe, a drugie fałszywe
- [ ] Oba zdania składowe są fałszywe
> Wyjaśnienie: Koniunkcja jest prawdziwa wyłącznie wtedy, gdy oba jej człony są prawdziwe. Prawdziwość przynajmniej jednego członu wystarcza dla alternatywy nierozłącznej; przy jednym lub dwóch członach fałszywych koniunkcja jest fałszywa.

### Alternatywa nierozłączna (p∨q) jest fałszywa wtedy i tylko wtedy, gdy:
- [ ] Jedno ze zdań składowych jest fałszywe
- [ ] Oba zdania składowe są prawdziwe
- [x] Oba zdania składowe są fałszywe
- [ ] Przynajmniej jedno zdanie składowe jest prawdziwe
> Wyjaśnienie: Alternatywa nierozłączna jest fałszywa tylko przy dwóch fałszywych członach. Gdy choć jeden jest prawdziwy, całość jest prawdziwa; samo stwierdzenie, że jeden jest fałszywy, nie rozstrzyga wartości całości.

### Poprawny podział logiczny musi być:
- [x] Wyczerpujący i rozłączny
- [ ] Tylko wyczerpujący
- [ ] Tylko rozłączny
- [ ] Naturalny i wielostopniowy
> Wyjaśnienie: Poprawny podział logiczny obejmuje cały dzielony zakres, a jego człony się nie nakładają. Sama wyczerpującość lub rozłączność nie wystarcza; naturalność i wielostopniowość nie są konieczne.

### Podział dychotomiczny to podział:
- [ ] Na trzy lub więcej członów
- [ ] Według wielu różnych zasad jednocześnie
- [ ] Wielostopniowy zakresu nazwy
- [x] Dwudzielny według cech kontradyktorycznych (sprzecznych)
> Wyjaśnienie: Podział dychotomiczny dzieli zakres na dwa człony według cechy i jej zaprzeczenia. Nie jest podziałem na co najmniej trzy człony, według wielu zasad ani z definicji podziałem wielostopniowym.

### Klasyfikacja to:
- [ ] Pojedynczy podział logiczny zakresu nazwy
- [x] Wielostopniowy podział logiczny z dalszym podziałem otrzymanych członów
- [ ] Wyróżnianie typów przedmiotów
- [ ] Podział według cech kontradyktorycznych
> Wyjaśnienie: Klasyfikacja to wielostopniowy podział logiczny: otrzymane człony dzieli się dalej. Pojedynczy podział nie wystarcza, wyróżnianie typów to typologia, a dychotomia opisuje sposób podziału na dwa człony.

### Implikacja materialna (p→q) jest fałszywa tylko wtedy, gdy:
- [ ] Poprzednik jest fałszywy, a następnik prawdziwy
- [ ] Oba zdania składowe są fałszywe
- [x] Poprzednik jest prawdziwy, a następnik fałszywy
- [ ] Oba zdania składowe są prawdziwe
> Wyjaśnienie: Implikacja materialna jest fałszywa tylko przy prawdziwym poprzedniku i fałszywym następniku. Każda z pozostałych trzech konfiguracji daje implikację prawdziwą.
