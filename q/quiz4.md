# Relacje, oceny i normy, modalności

### W opisie relacji xRy, jak nazywa się element stojący na miejscu „x”?
- [ ] Następnik relacji
- [ ] Konwers relacji
- [x] Poprzednik relacji
- [ ] Dziedzina relacji
> Wyjaśnienie: W zapisie xRy element x jest poprzednikiem, a y następnikiem relacji. Konwers jest relacją odwrotną, a dziedzina — zbiorem elementów występujących jako poprzedniki, nie nazwą roli pojedynczego x.

### Jak nazywa się relacja odwrotna względem relacji R (np. „być starszym od” vs „być młodszym od”)?
- [ ] Relacja dopełniająca
- [x] Konwers relacji
- [ ] Relacja zwrotna
- [ ] Relacja spójna
> Wyjaśnienie: Konwers odwraca kolejność argumentów: x pozostaje w konwersie R do y wtedy, gdy yRx. Relacja dopełniająca obejmuje pary spoza R; zwrotność i spójność są własnościami relacji, a nie nazwami jej odwrotności.

### Relacja jest asymetryczna, gdy zachodzi warunek:
- [ ] Jeśli xRy, to yRx
- [ ] Dla każdego x zachodzi xRx
- [ ] Jeśli xRy i yRz, to xRz
- [x] Jeśli xRy, to nie yRx
> Wyjaśnienie: Asymetryczność oznacza, że z xRy wynika niezachodzenie yRx. Pozostałe warunki opisują kolejno symetryczność, zwrotność i przechodniość.

### Relacja R jest przechodnia (tranzytywna), gdy:
- [ ] Dla każdego x zachodzi xRx
- [x] Jeśli xRy i yRz, to xRz
- [ ] Jeśli xRy, to yRx
- [ ] Dla każdych x,y zachodzi xRy lub yRx
> Wyjaśnienie: Przechodniość oznacza, że xRy i yRz pociągają xRz. Pozostałe opcje opisują zwrotność, symetryczność i warunek porównywalności; przy ścisłym porządku porównywalność dotyczy różnych elementów.

### Który zestaw własności charakteryzuje relację ścisłego porządku liniowego w danej klasie przedmiotów?
- [ ] Symetryczność, zwrotność, przechodniość
- [ ] Nonsymetryczność, nontranzytywność, spójność
- [x] Asymetryczność, przechodniość, spójność
- [ ] Zwrotność, spójność, atranzytywność
> Wyjaśnienie: Ścisły porządek liniowy jest asymetryczny, przechodni i spójny: każde dwa różne elementy są porównywalne. Zwrotność i symetryczność z przechodniością charakteryzują relację równoważności; pozostałe zestawy nie zapewniają ścisłego porządku liniowego.

### Relacja równościowa (w danej klasie) to relacja, która jest jednocześnie:
- [x] Symetryczna, przechodnia i zwrotna
- [ ] Asymetryczna, przechodnia i spójna
- [ ] Symetryczna, atranzytywna i zwrotna
- [ ] Nonsymetryczna, przechodnia i spójna
> Wyjaśnienie: Relacja równościowa, czyli równoważności, jest zwrotna, symetryczna i przechodnia. Asymetryczność oraz atranzytywność nie są jej warunkami; sama spójność nie zastępuje wymaganych własności.

### Wypowiedź typu „Brawo!” (bez elementu opisu stanu rzeczy) najtrafniej scharakteryzować jako:
- [ ] Zdanie opisowe prawdziwe lub fałszywe
- [ ] Definicję projektującą
- [ ] Wypowiedź o kwalifikacji prawnej czynu
- [x] Wypowiedź oceniająca, której nie przypisuje się prawdziwości/fałszywości
> Wyjaśnienie: W tym ujęciu „Brawo!” wyraża aprobatę i nie opisuje stanu rzeczy, któremu przypisywalibyśmy prawdę lub fałsz. Nie definiuje wyrażenia ani nie kwalifikuje prawnie czynu.

### Norma postępowania to w najprostszym ujęciu wypowiedź, która:
- [ ] Opisuje fakty i podlega ocenie prawda/fałsz
- [x] Nakazuje lub zakazuje adresatowi określonego zachowania w danych okolicznościach
- [ ] Wyraża wyłącznie przeżycie aprobaty lub dezaprobaty
- [ ] Stwierdza konieczność logiczną jakiegoś zdania
> Wyjaśnienie: Norma postępowania wyznacza adresatowi nakazane lub zakazane zachowanie w określonych okolicznościach. Opis faktów, samo wyrażenie aprobaty i stwierdzenie konieczności logicznej pełnią inne funkcje.

### Norma jest konkretna, gdy:
- [x] Nakazuje jednorazowe postąpienie w określony sposób
- [ ] Nakazuje postępować stale lub zawsze, gdy wystąpią dane okoliczności
- [ ] Jej adresat jest określony rodzajowo
- [ ] Jest skuteczna społecznie w ujęciu behawiorystycznym
> Wyjaśnienie: Konkretność normy dotyczy jednorazowo wyznaczonego zachowania. Powtarzalne zachowania wyznacza norma abstrakcyjna; rodzajowe określenie adresata oznacza generalność, a skuteczność społeczna jest odrębną kwestią.

### Uzasadnienie tetyczne obowiązywania normy polega na tym, że:
- [ ] Norma jest dobra moralnie lub prowadzi do dobrych skutków
- [x] Normę ustanowił (i nie odwołał) ktoś uznawany za mającego władzę nad adresatami
- [ ] Adresaci w większości spontanicznie postępują zgodnie z normą bez względu na sankcje
- [ ] Norma wynika logicznie z twierdzeń matematycznych
> Wyjaśnienie: Uzasadnienie tetyczne odwołuje się do ustanowienia normy przez uznany autorytet. Dobro normy uzasadnia ją aksjologicznie; faktyczne przestrzeganie dotyczy skuteczności, a wynikanie z twierdzeń matematycznych nie jest ustanowieniem normy.

### W interpretacji tetycznej zwrot „musi być A” znaczy, że:
- [ ] A jest nieuchronnie spowodowane przez czynniki przyczynowe
- [ ] A wynika logicznie z przyjętych zdań
- [ ] Mówiący jest silnie przekonany, że A
- [x] Zrealizowanie A jest nakazane przez obowiązującą normę
> Wyjaśnienie: W interpretacji tetycznej „musi” wyraża nakaz wynikający z obowiązującej normy. Nieuchronność przyczynowa, wynikanie logiczne i przekonanie mówiącego odpowiadają innym interpretacjom modalnym.

### Zdanie „W trójkącie prostokątnym o przyprostokątnych 3 i 4 przeciwprostokątna musi mieć 5” wykorzystuje „musi” przede wszystkim w interpretacji:
- [ ] Aksjologicznej.
- [ ] Tetycznej.
- [x] Logicznej.
- [ ] Dynamicznej.
> Wyjaśnienie: Długość 5 wynika z twierdzenia Pitagorasa w geometrii euklidesowej: kwadrat przeciwprostokątnej to 9 + 16 = 25. „Musi” wyraża tu konsekwencję matematyczną, a nie ocenę, nakaz normy lub zdolność do działania.

### Jeśli czyn c nie jest zakazany (ze względu na daną normę), to jest on:
- [x] Dozwolony
- [ ] Nakazany
- [ ] Sprzeczny
- [ ] Atranzytywny
> Wyjaśnienie: Jeżeli czyn nie jest zakazany ze względu na daną normę, jest w tym względzie dozwolony w sensie słabym. Nie oznacza to, że jest nakazany; sprzeczność i atranzytywność nie są odpowiednimi kwalifikacjami deontycznymi czynu.
