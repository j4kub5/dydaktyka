* Wspólne zasady zajęć / Shared class rules
Wspólne zasady dla zajęć anglojęzycznych są w [[file:g/class-rules.org]].
Edytuj je w tym pliku, aby zmiana objęła wszystkie korzystające z niego kursy.

Shared rules for English-language classes are in [[file:g/class-rules.org]].
Edit that file to update every course that includes it.

Aby dołączyć zasady do kolejnego kursu, użyj dyrektywy poniżej.
Dostosuj =:minlevel= do poziomu nagłówków w dokumencie (3 w Theory of Law,
2 w FinTech Law).

To reuse the rules in another course, use the directive below.
Adjust =:minlevel= to the document's heading level (3 in Theory of Law,
2 in FinTech Law).

#+begin_example
#+include: "./g/class-rules.org" :minlevel 2
#+end_example
